# Server-Rescue

Browserbasiertes Escape-Game zu Brüchen für Klasse 6: Anteile, Kürzen und Erweitern, Vergleichen.

Der Hacker Glitch hat den Gameserver gesperrt. Knackt fünf Firewalls, sammelt die Code-Fragmente und rettet den Server!

- Läuft komplett im Browser, ohne Anmeldung, ohne Cookies, ohne Tracker und ohne externe Aufrufe.
- Der Spielstand wird nur lokal auf dem Gerät gespeichert.
- Bruchdarstellung mit [KaTeX](https://katex.org) (lokal eingebunden, MIT-Lizenz).
